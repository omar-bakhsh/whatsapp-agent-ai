# بوت واتساب "مركز متخصص مازدا" الذكي (نظام التكرار المزدوج) 🚗🤖

بوت واتساب متطور مدعوم بمحركين ذكاء اصطناعي لضمان استمرارية الخدمة 24/7، مصمم خصيصاً لخدمة عملاء مركز مازدا.

## ✨ المميزات الحديثة
- **نظام التبديل التلقائي (Smart Fallback):** يستخدم البوت محرك **Gemini 1.5** كخيار أساسي، وفي حال حدوث ضغط أو نفاذ الحصة المجانية، ينتقل تلقائياً لمحرك **Llama 3 (Groq)** بلمح البصر.
- **ذكاء اصطناعي تفاعلي:** يفهم استفسارات الصيانة، الميكانيكا، الكهرباء، والبرمجة.
- **إدارة المواعيد:** حجز مبدئي ذكي حتى الساعة 3:00 مساءً فقط.
- **جدول صيانة متكامل:** مدرب على جداول صيانة مازدا الدورية من 10k إلى 160k كم.
- **توجيه ذكي:** يعطي أرقام الفروع في الدوام، ورقم طوارئ (أبوعلي) خارج الدوام.
- **فلترة المحادثات:** يتفاعل فقط مع الأفراد ويتجاهل المجموعات تماماً.

---

## 🚀 طريقة التشغيل

### 1. المتطلبات
- [Node.js](https://nodejs.org/) مثبت على الجهاز.
- حساب في [Google AI Studio](https://aistudio.google.com/) وحساب في [Groq Cloud](https://console.groq.com/).

### 2. التثبيت
```bash
npm install
```

### 3. الإعداد (الملف السري)
افتح ملف `.env` وقم بتعبئة المفاتيح التي حصلت عليها:
```env
GEMINI_API_KEY=ضع_مفتاح_جوجل_هنا
GROQ_API_KEY=ضع_مفتاح_جروق_هنا
```

### 4. قمة التحكم (عقل البوت)
أهم ملف في المشروع هو `prompt.js`. من خلاله يمكنك:
- إضافة أو حذف خدمات (ميكانيكا، كهرباء، إلخ).
- تحديث أوقات العمل وأرقام الجوالات.
- تعديل مواقع الفروع.
- تحديث تفاصيل الصيانة الدورية.
*(أي تعديل هنا يتطلب إعادة تشغيل البوت ليتم تطبيقه).*

### 5. التشغيل
```bash
node index.js
```

---

## 📁 ملفات المشروع
- `index.js`: المحرك البرمجي الرئيسي للربط مع واتساب والذكاء الاصطناعي.
- `prompt.js`: الملف المخصص لك لتعديل بيانات المركز وسلوك البوت.
- `.env`: يحفظ مفاتيح الـ API السرية.
- `package.json`: يحتوي على المكتبات المستخدمة (Axios, Whatsapp-web.js, etc).

## ⚠️ نصيحة تقنية
لضمان عمل البوت للأبد وبشكل مجاني، تأكد من توفير مفتاحي الـ API (جوجل وجروق). النظام مصمم ليحمي عملك من التوقف المفاجئ.
